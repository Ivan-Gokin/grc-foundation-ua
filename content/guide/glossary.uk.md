# Глосарій

| Українською | English | Значення |
|---|---|---|
| СУІБ | ISMS | система управління інформаційною безпекою |
| Положення про застосовність | Statement of Applicability (SoA) | перелік заходів ISO/IEC 27001 з рішенням і обґрунтуванням |
| цільовий профіль | Target Profile | бажаний стан результатів NIST CSF 2.0 |
| зацікавлена сторона | interested party | особа чи організація, яка може впливати на рішення або на яку вони впливають |
| ОКІ / ОКІІ | critical (information) infrastructure object | об'єкт критичної (інформаційної) інфраструктури |
| КСЗІ | KSZI | комплексна система захисту інформації з державною експертизою |
| ТЗІ | TZI | технічний захист інформації |
| параметр, визначений організацією | organisation-defined parameter (ODP) | значення, яке стандарт залишає на розсуд організації |
